# SkillArena

**Compete. Improve. Climb the Rankings.**

SkillArena is a NEAR-powered skill gaming platform with four competitive mini-games.

## Games
- Reflex Rush
- Memory Matrix
- Precision Strike
- Clutch Shot

## NEAR Integration
- HOT Wallet Connect
- On-chain score submissions
- Smart-contract leaderboards
- NEAR wallet account IDs

**Network:** NEAR Testnet

**Contract:** smasj01.testnet

**GitHub:** https://github.com/SmashDev01/SkillArena

## Prototype Limitations
- Scores are player-submitted and are not independently verified.
- The contract currently runs on NEAR Testnet.

Built for the NEAR Hackathon.
